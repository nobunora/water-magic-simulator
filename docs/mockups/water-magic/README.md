# 水魔法選択モック

水魔法の新規解析の既定範囲は±100 m（0.5 m格子で16万セル）。短時間魔法の結果出力は原則0.2秒刻み、600フレーム上限に応じて間隔を広げる。内部計算は最大0.01秒。ベクトル・粒子は元の表示密度で「ズームに合わせる」のみ。保存結果は元の範囲・出力時刻を維持する。

以前の最大値指定: 当時の全16件は推定最大水量を初期設定とする。Nami・FFIII Tsunamiの縦横を修正し、Tales Tidal Waveは半径9.8 mの有限範囲に変更。寸法・面積は小数1桁表示、緯度経度と内部計算の精度は保持。[範囲推定の根拠](../../specs/water-magic-range-estimates.md)参照。

## 実装版（最新）

0.5 m格子（1 mを2×2分割）で実解析する。既定の±100 mは16万セル。ベクトル・粒子の表示密度は元の「ズームに合わせる」のみで、GPU粒子表示を維持する。

選択肢は推定最大総水量が5 m³を超える14件を最大水量の少ない順に表示。5 m³以下の8件を外し、DQVII、FFVI Advance、FFXV、クロノ・クロス、黄金の太陽 失われし時代、ロマサガ3の6件を追加した。初期選択はDQVIIのメイルストロム（2500 m³）。各魔法にはゲーム識別画像と実ゲーム映像のGIF・静止画を収録し、選択した1件のみ自動再生する。住所検索と編集可能な緯度・経度入力を利用できる。

給水・緩和は内部的に秒で計算する。表示単位は魔法継続時間のみを基準に、300秒未満は秒、300秒以上は分。緩和時間は基準に含めない。計算刻みは最大0.01秒、短時間魔法の結果出力は原則0.2秒刻み、長時間は原則10秒刻み（600フレーム上限で調整）。時間スライダーは保存データのある時刻だけを使う。

水深は選択した1時刻だけの専用読込み経路、標高・解析格子は静的な情報だけ、ベクトル・GPU粒子は可視範囲の必要な項目だけを読む。旧IDと結果ZIPの互換性は保持する。

推定式・資料・映像の切出し時刻・性能測定は[大水量魔法の追加と水深表示高速化](../../specs/water-magic-volume-expansion.md)、解析契約は[実装詳細書](../../specs/water-magic-implementation.md)を参照。

魔法のリストをクリックすると、効果範囲が見える大きさへ地図を自動ズームする。同じ魔法の再クリックも対応。全体魔法では解析範囲を収める。手動ズーム・角度などの編集は表示を勝手に戻さない。拡大表示に合わせて方向矢印の表示長も制限し、先端ハンドルを操作できるようにする。実際の水量・効果範囲の寸法・解析領域は表示ズームによって変更しない。

## 既存UIに組み込んだモック（2026-10-03追加）

既存のReact UIで「四日市」などのサンプル選択をHealing Rainに置き換える。
地図・解析領域・住所検索・結果ZIP読込は既存UIを使用する。
通常の降雨UIのヘッダーから「水魔法モックを開く」でも移動できる。
選択欄は「魔法名＋推定最大水量」「ゲーム名」の2行。水量は小数1桁のm³で表示し、「推定総水量」の文字は省略する（利用者の追加指定）。元の推定範囲と設定値の精度は保持する。
設定欄の共通見出しは「魔法の設定」。給水範囲の形状は魔法ごとに表示する。Healing Rainは円であり、他の魔法には扇形・帯状の長方形・任意の多角形などを想定する。この1件モックの形状操作は円のみ。

最新の利用者指定により、画面は「1. 条件（住所検索・解析範囲）」→「2. 魔法の設定」→「3. 実行状態」の順。
魔法と解析領域の位置は住所検索候補の選択で更新する。「1. 条件」の住所検索の下に元の緯度・経度の直接入力欄を表示する。中心再配置ボタンは表示しない。
GIFは魔法選択で自動再生し、再生・停止・表示切替・画像設定の操作UIは表示しない。
動きを減らす設定で静止画から始める以前のモック方針も、この自動再生指定で上書きする。
方向は0〜360°の入力と地図矢印で確認する。真北0°・東90°・時計回りで、地図の回転から独立する。
矢印は解析枠と同じ投影座標のSVGオーバーレイで、黒10px・赤5pxの二重線をGIFより上に表示する。
丸い先端ハンドルは通常非表示。マウスが矢印の線分から60 CSS px以内に近づくと表示し、ドラッグ中は表示を保つ。
ハンドルのドラッグは緯度経度へ逆投影して角度入力と同期し、配置点は動かさない。ドラッグ中だけ地図のパンを停止し、終了・中断で元に戻す。
Chromeで遠い位置の非表示→近接表示→先端ドラッグによる角度更新→離れた位置の非表示を確認。
回帰18件成功。新規SVG・ドラッグ試験は黒赤の描画、角度更新、60px境界、ドラッグ中の表示維持、中断後のパン復帰を検証する。
効果範囲は黒10px・青5pxの二重線で表示する。「効果範囲（モック）」で円／解析範囲全体を切り替えて確認できる。全体の選択はHealing Rainの正式仕様の変更ではなく、全体魔法の表示確認用。
全体の場合は、解析領域の地図投影後の各辺から垂直方向に5 CSS px内側へ線の中心を移す。ズーム・回転で再計算し、物理的な給水面積は縮めない。画面上で小さすぎて5px内側の範囲が成立しない場合は線を描かない。
Chromeで全体表示の四隅と解析枠の差が約5pxであること、ズーム後も維持されることを確認。型チェック・19件の回帰・ビルド成功。
Healing Rainは円形のため角度は矢印の確認に使い、円の給水範囲は変えない。指向性のある魔法の形状実装・水理計算は今後の対象。
