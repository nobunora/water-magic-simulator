# 最高流速・最高水深の上位10地点（2026-10-04）

利用者の追加指示により、結果画面の「最大深度箇所」と新設「最高速度箇所」で、各指標の上位10地点とそのピーク時刻へ移動する。両ボタンは独立して1位→2位→…→10位→1位と巡回する。対象が10地点未満ならその件数で巡回する。

## 順位と移動

- 解析ネイティブセル／適応格子の面ごとに、保存された出力時刻のピークを選ぶ。同じ地点を異なる時刻で重複登録しない。対象は実際に利用可能な出力時刻だけ。同値はセル順、同じ地点の同値時刻は最初の出力を採用する。
- 水深順位は保存時刻の水深による。SFINCSが内部計算刻みで記録するhmaxと、保存時刻のピークには小さな差がありうる。未保存の内部時刻に移動したように表示しない。
- 流速は既存のネイティブ流速表示と同じu・vから√(u²+v²)。非有効セル、非有限値、表示用の乾燥閾値以下の水は流速順位から除外する。入力の初速上限で解析結果の流速を切り詰めない。
- 移動時は再生を停止し、時刻別水深へ切り替え、地図中心と地点マーカー、時刻スライダと地点検査を同時に更新する。流れ表示の選択は保持する。
- 地点欄に指標名・順位・対象件数・ピーク値・ピーク時刻を表示する。流速は時速、小数1桁。手動の地点選択では巡回地点の順位表示を解除する。
- 出力なし／流速なしでは該当ボタンを無効にする。読込み失敗は表示し、再試行できる。

## 比較欄

「比較」は巡回で選んだ地点のピーク時刻について表示する。セル内の水の運動エネルギーを、身近な重さの物体が動く速度に換算する。時刻を変更したらピーク時刻の比較値を現在値として表示しない。

水の質量 = 水深 × セル面積 × 1000 kg/m³。

水の運動エネルギー = ½ × 水の質量 × 流速²。

換算時速 = 3.6 × 流速[m/s] × √(水の質量 / 比較対象の質量)。

- プリウス: [トヨタ主要諸元（2026年10月）](https://toyota.jp/pages/contents/prius/005_p_001/pdf/prius_spec_202610.pdf)のG・2WD、1400 kg。
- プリウス換算が時速30 km未満なら、力士150 kgへ切り替える。時速30 km以上はプリウスを使う。150 kgは[日本相撲協会の幕内平均155.26 kgの紹介](https://sumo.or.jp/Entertainment/quiz/1322/)を参考に丸めた比較用の重さ。切替値30 km/hは利用者の指定。
- 力士の換算表示は秒速（m/s、小数2桁）と100 m走の所要時間（秒、小数1桁）を併記する。100 m÷換算速度で一定速度の所要時間を求め、静止時は換算不可と表示する。プリウスは時速表示を維持する。水量とエネルギーの計算方式は、この表示変更では変更しない。
- 時速0.1 km未満の非ゼロ値は「時速0.1 km未満」、静止は0.0と表示する。
- 比較対象の重さ、セル内の水の質量、実際の流速を表示する。詳細でセル面積・水深・密度・式・出典を確認できる。これはセル内の水の運動エネルギーであり、全水量のエネルギーや衝突力ではない。格子面積が変われば比較値も変わる。
